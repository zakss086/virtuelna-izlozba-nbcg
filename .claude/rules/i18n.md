# Internationalization

- Every UI string comes from `t('key')` of `useI18n()`; add the key to BOTH `me` and `en` in `src/lib/messages.ts`
- Montenegrin is written in Latin script (ijekavian forms, e.g. "izložba", "sljedeće"), never Cyrillic
- Content fields that users see are `Localized` (`{ me, en }`) and rendered with `l(value)`
- Never concatenate translated fragments into sentences; use one key with `{placeholder}` instead
- Switching language must not change the URL or lose state
