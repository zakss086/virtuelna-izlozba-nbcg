# Design references

Sites that informed `frontend/DESIGN.md` (colors, fonts and tone come from the first one):

- https://nb-cg.me: National Library of Montenegro (gold, warm white, ink, serif headings)
- https://dlib.me: Digital Library of Montenegro (collections structure)
- Virtual exhibition portals of national libraries in the region (the idea of exhibition templates, which we modernized and extended)

Screenshots of the finished app are in `docs/screenshots/` at the repo root.
